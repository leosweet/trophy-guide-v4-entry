Leonida Legend — the complete offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words that cites its sources, a 5-stage roadmap to the platinum, a missable-timeline view, and a checklist that saves in the browser with export/import, filters, search, sorting and a spoiler setting. Post-release research (checked 20 Nov 2026) resolves three of the five secret trophies that were unknown at launch — In The Beginning…, Capital Offense and The Truth Is Out There — and honestly marks the two that still have no confirmed method (Bad Luck, I Guess and Ten Pin) instead of guessing.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` from any static server. It works with the network off.

## Build the submission

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
